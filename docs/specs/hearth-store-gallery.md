## 1. Что строим

Окно **Hearth Store** — та же модель, что Wallpaper Gallery (`wallpaper-library.js/.css` в сборке): ленивое окно поверх рабочего стола, стекло, Esc закрывает, выбор карточки → нижняя панель действий, просмотрщик.
Открывается: кнопкой **See all →** в виджете Hearth Store, и пунктом правого клика по рабочему столу «Hearth Store». Значков настроек внутри виджетов не добавлять.

Новые файлы (owner — агенты этого ТЗ):
- `addon/store-gallery.js` — окно, вкладки, сетка, детальный просмотр, примерка, покупка.
- `addon/store-gallery.css` — стили окна (переиспользовать токены HearthUI: стекло, радиусы, шрифты — смотреть `wallpaper-library.css`, значения копировать, не изобретать).
- `addon/store-catalog.js` — данные витрины (§4), `window.HearthStoreCatalog`.
- `addon/store-previews/` — превью-картинки (§5).
- Тесты `tests/store-gallery-*.test.js` для чистой логики (фильтр по вкладке, состояния карточки, счётчик owned, цена/формат, бандл-состав).

Покупка, сессия и владение — **только через существующие API**: `HearthSolana.openBridge(action, sku)`, `HearthSolana.isOwned(sku)`, `HearthSolana.getOwned()`, `HearthPass.methodFor(sku)`, `HearthPassClient.isPassOwned`. Ничего нового в мосте/программе.

```
│ ┌────────────┐ ┌────────────┐ ┌────────────┐                         │

│ │  16:10     │ │            │ │            │   ≥1180px; 2 колонки     │
│ └────────────┘ └────────────┘ └────────────┘   <1180px; 1 <720px      │
│ ⛰ Aurora          [$1.99 USDC]                                        │  карточка: иконка типа · имя · «by автор» · цена-пилюля
│   by Hearth Originals                                                 │
│ … второй ряд …                                                        │
│──────────────────────────────────────────────────────────────────────│
│ ♡ Creator gets 95% ⓘ                         [◎ USDC · Connected ●]  │  футер
└──────────────────────────────────────────────────────────────────────┘
```

- Окно: ширина `min(1240px, 92vw)`, высота по контенту до `86vh`, скролл внутри сетки (не всей страницы). Стекло как у Wallpaper Gallery.
- Вкладки — горизонтальная лента, иконка + подпись; при нехватке ширины — горизонтальный скролл ленты (не перенос).
- Карточка: превью `aspect-ratio:16/10`, `border-radius` как у карточек галереи; под превью — иконка типа, название (500), «by …» (вторичный), справа цена-пилюля.
- Пилюля цены: `$1.99 USDC`; бандл — подпись `BUNDLE` под ценой; Supporter — бейдж `INCLUDES EXCLUSIVE THEME`.
- Футер: «Creator gets 95%» + ⓘ (тултип: «95% of every sale goes straight to the creator's wallet on Solana; 5% supports HearthUI»); справа чип кошелька: `USDC · Connected` (зелёная точка) / `Connect wallet` (кнопка → `openBridge('signin')`).
- Счётчик `N/M owned` — по покупаемым позициям.

## 3. Состояния и действия

| Состояние карточки | Вид | Действие по клику на цену |
|---|---|---|
| Можно купить | цена-пилюля | Buy → `openBridge(methodFor(sku)==='pass'?'buy':'pay', sku)` |
| Куплено | пилюля `Owned ✓`, у превью маленькая галочка | Apply (тема/иконки/часы) |
| Применено | `Applied` | — |
| Скоро (нет на цепочке) | пилюля `Soon`, превью приглушено на 20% | неактивно, тултип «Coming soon» |
| Нет кошелька | цена видна, клик → Connect wallet | `openBridge('signin')` |

**Детальный просмотр** (клик по превью; как viewer галереи): крупное превью, описание (1–2 строки), автор, «Creator gets 95%», кнопки **Try on** · **Buy $X** (или **Apply**), для купленного — **View receipt ↗** (Solana Explorer devnet: адрес квитанции PDA `HearthPass.derivePassPda(wallet, sku)`; для `usdc` — транзакция). ←/→ листают в пределах вкладки, Esc закрывает просмотр, второй Esc — окно.

**Try on (примерка):** применяет тему/иконки/часы временно на 30 с, окно сворачивается, сверху плашка «Preview · 0:30 · Buy $1.99 · Revert». По окончании или Revert — откат к прежнему состоянию (сохранить и восстановить ровно то, что меняли). Не писать в постоянное хранилище.

**Разблокировка:** на `chrome.storage` change `hearth.solana.owned` — у карточки анимация (замок → галочка, 300 мс, только `transform/opacity`, уважать `prefers-reduced-motion`), тост «Aurora unlocked · View receipt ↗».

**Загрузка/ошибки:** скелетоны карточек до готовности каталога/owned; ошибка RPC — плашка над сеткой «Can't reach Solana devnet · Retry» (owned из кэша); пустая вкладка — «Nothing here yet».

## 5. Превью-картинки

- Темы: скриншот рабочего стола HearthUI с применённой темой, 1280×800 → `webp` ~80 КБ, + миниатюра 480 px.
- Иконки: сетка 2×3 иконок дока в стиле пака на размытом фоне.
- Часы: виджет часов в стиле на нейтральном фоне.
- Паки обоев: коллаж 3 миниатюр.
- Live: кадр сцены + значок ▶.
- Делать скриншотами из демо-сборки (встроенный браузер, `npm run build:demo`, viewport 1440×900); никаких картинок из интернета.

## 6. Новые позиции на цепочке (делает оркестратор, не агенты)

`theme_midnight` 1.99, `icons_mono` 2.99, `clock_orbit` 0.99, `bundle_focus` 4.99 — одной командой `program/scripts/create-themes.cjs` (дописать в CATALOG). ## 7. Критерии приёмки (проверка в браузере, скриншоты)

1. Окно открывается из виджета (See all) и из правого клика; Esc закрывает; фокус возвращается.
2. 7 вкладок, Featured = 6 карточек; на 1440×900 — 3 колонки, на 1024 — 2, на 700 — 1; ничего не обрезано (aw §15).
3. Карточки: превью, имя, «by Hearth Originals», цена/Owned/Soon/Free — все 4 вида видны.
4. Купленная ранее Aurora показывается как Owned ✓ сразу при открытии (из цепочки, не из localStorage).
5. Try on Aurora → тема на 30 с → автокат; Revert работает; хранилище не изменилось.
6. Покупка новой позиции (Dune) через мост → карточка анимированно становится Owned без перезагрузки; View receipt открывает explorer.
7. Footer: «Creator gets 95%» с тултипом; чип кошелька в двух состояниях.
8. Консоль без ошибок (кроме ожидаемого 401 IPFPS без входа).
9. `prefers-reduced-motion` — без анимаций.
